# Play Store 스크린샷

Play Console > 스토어 등록정보 > 그래픽 자산 > 휴대전화 스크린샷에 업로드할 자료입니다.

## 업로드 권장 순서

1. `01-home.png` — DockMode 홈, 충전 상태와 대기 화면 시작 CTA 강조 (세로)
2. `03-standby-minimal.png` — 야간 호박색 미니멀 시계 (가로)
3. `04-standby-digital.png` — 디지털 + 다음 일정 글래스 패널 (가로)
4. `05-standby-calendar.png` — 캘린더 중심 + 오늘 일정 리스트 (가로)
5. `02-settings.png` — 시계 스타일·토글·개인정보 카드 설정 (세로)

## Play Console 요건 메모

- 형식: JPEG 또는 PNG (현재 모두 PNG)
- 양 변 320–3840 px, 최대 종횡비 약 2:1
- 우리 캡처는 1080×2340(세로) / 2340×1080(가로) = 19.5:9 ≈ 2.17:1. Play Console은 19.5:9 폰 화면비를 수용하지만, 거부될 경우 좌우/상하에 패딩을 추가해 정확히 2:1로 맞춰 다시 업로드합니다.
- 한 화면당 2–8장 필요. 위 5종으로 충족.
