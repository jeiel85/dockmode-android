# Play Console 카테고리 / 타깃 사용자 / 가격 정책

## 카테고리

- **Play Console 입력값**: `생산성` (Productivity)
- **차순위 후보**: `도구` (Tools)

### 근거

- 시계·일정 대시보드는 사용자의 일과를 돕는 **유틸리티/생산성** 영역으로 분류된다.
- 일정 데이터 표시가 핵심 차별점이므로 단순 도구(Tools)보다 생산성(Productivity)이 정확하다.

## 태그 (선택)

- Clock / Schedule / Calendar / Standby / Night clock / Bedside / Dock

## 가격 정책

- **무료** (In-app product 없음, 광고 없음)

## 콘텐츠 가이드라인 / 타깃 사용자

| 항목 | 값 |
|---|---|
| 타깃 연령 | 13세 이상 (Everyone / 전체이용가) |
| 자녀 보호 정책 | 해당 없음 (Designed for Families 대상 아님) |
| 광고 포함 | 아니요 |
| 학교/교육 카테고리 | 해당 없음 |

## 국가 / 언어 배포

- 1차: 한국, 미국
- 2차: 일본(`ja`), 중국 본토 제외 중화권(`zh`) — 향후 i18n 추가 시점에 확대
- 기본 언어: `ko-KR` (`ko` 우선)
- 함께 등록할 언어: `en-US`

## 외부 제약

- 정부 앱 / 금융 / 의료 / 도박 / 결제 / 어린이용 카테고리 정책: 해당 없음
- 데이터 위치: 단말기 로컬만 사용. 외부 서버 데이터 위치 신고 대상 아님.
