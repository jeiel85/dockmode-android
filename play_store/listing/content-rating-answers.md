# Play Console 콘텐츠 등급 (IARC) 설문 답변 초안

Play Console > 앱 콘텐츠 > 콘텐츠 등급에서 답변할 IARC 설문 항목입니다. v0.1 기준이며, 등급에 영향을 줄 콘텐츠가 추가되면 반드시 함께 갱신해야 합니다.

## 카테고리 선택

- **Utility, Productivity, Communication, or Other** 카테고리에서 답변합니다.

## 설문 답변

| 항목 | 답변 |
|---|---|
| 폭력적 콘텐츠 (실제·만화 폭력, 유혈 등) | 없음 |
| 성적 콘텐츠 / 노출 | 없음 |
| 욕설·비속어 | 없음 |
| 약물·알코올·담배 묘사 | 없음 |
| 도박 (시뮬레이션 포함) | 없음 |
| 공포·잔혹 묘사 | 없음 |
| 거친 유머 | 없음 |
| 차별·증오 표현 | 없음 |
| 사용자 위치 공유 | 없음 (위치 권한 미요청) |
| 사용자 생성 콘텐츠 공유 | 없음 |
| 사용자 간 직접 메시지 / 채팅 | 없음 |
| 디지털 구매 (앱 내 구매, 광고로 외부 구매 유도) | 없음 |
| 광고 노출 | 없음 (광고 SDK 미포함) |
| 사용자 데이터 외부 공유 | 없음 (네트워크 권한 미요청) |
| 도구·시뮬레이션·교육 외 기능 | 없음 |

## 예상 등급

- **IARC**: 모든 지역 **3+ / Everyone / 전체이용가** 수준 예상

## 갱신 트리거

다음 변경 발생 시 설문을 다시 채워야 합니다.

- 외부 콘텐츠(웹뷰, 뉴스 피드, 사용자 게시판 등) 추가
- 광고 노출 시작
- 인앱 구매 추가
- 카메라/마이크 등 사용자 생성 콘텐츠 입력 추가
- 사용자 간 채팅 기능 추가
