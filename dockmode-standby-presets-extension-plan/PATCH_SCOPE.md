# Patch Scope

## 1. 이번 패치의 성격

이 문서는 DockMode의 초기 구현 이후 적용하는 **추가 개발 패치 범위**를 정의합니다.

이번 패치는 `feat: 대기모드 프리셋 추가`에 해당합니다.

## 2. 허용 범위

- Standby 화면의 프리셋 모델 추가
- 프리셋별 Composable 추가
- 테마 프리셋 모델 추가
- 프리셋 저장/복원
- 설정 화면에 프리셋 선택 UI 추가
- StandbyActivity와 StandbyDreamService의 렌더링 공유 구조 보강
- 번인 방지용 최소 offset 로직 추가
- 문서 갱신
- 테스트 또는 미리보기 추가

## 3. 제한 범위

아래 항목은 기존 구조가 없다면 신규로 크게 만들지 말고, 후속 작업으로 기록합니다.

- 복잡한 온보딩
- 상세 사용자 계정 설정
- 서버 동기화
- 실시간 날씨
- 사진 라이브러리 직접 접근
- 고급 테마 스토어
- 사용자 커스텀 테마 편집기

## 4. 금지 범위

- 앱 ID 변경
- namespace 변경
- 저장소명 변경
- 기존 구현 전체 삭제 후 재작성
- 전체 파일 포맷팅
- 대규모 패키지 재구성
- 불필요한 대형 의존성 추가
- 네트워크 권한 추가
- 광고/분석/로그인 SDK 추가
- iPhone StandBy UI의 직접 복제

## 5. 기존 구조 우선 규칙

에이전트는 아래 순서로 판단합니다.

1. 기존 구현에서 이미 제공하는 모델/테마/설정 저장소가 있는지 확인합니다.
2. 있으면 기존 구조에 맞춰 작은 확장으로 구현합니다.
3. 없으면 이 계획서의 권장 구조를 최소 단위로 추가합니다.
4. 구조가 충돌하면 기존 구조를 우선하고, 충돌 사항을 `DECISIONS.md`에 기록합니다.
5. 불확실한 경우 컴파일 가능한 최소 구현을 완료하고 나머지는 `TASKS.md` 후속 작업으로 기록합니다.
