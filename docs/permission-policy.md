# 권한 구현 세부 정책

## READ_CALENDAR

요청 조건:

- 사용자가 HomeScreen에서 “캘린더 연동하기”를 누른 경우
- 사용자가 SettingsScreen에서 “일정 표시”를 켠 경우

요청 전 설명:

```text
오늘 일정과 다음 일정을 대기 화면에 표시하기 위해 캘린더 읽기 권한이 필요합니다. DockMode는 일정 정보를 기기 밖으로 전송하지 않습니다.
```

거부 상태 처리:

- StandbyScreen은 시계와 날짜를 계속 표시한다.
- 일정 영역에는 “캘린더 권한이 꺼져 있어 일정을 표시할 수 없습니다.”를 표시한다.
- 반복적인 권한 팝업을 띄우지 않는다.

다시 묻지 않음 상태:

- 앱 설정으로 이동하는 버튼을 제공한다.
- 시스템 설정을 직접 변경하려고 시도하지 않는다.

## 네트워크 권한

v1.0 범위에서는 추가하지 않는다.

추가가 필요한 경우:

- 날씨 API
- 외부 캘린더 REST API
- 분석/크래시 리포팅
- 앱 업데이트 확인

위 기능은 별도 승인과 개인정보 문서 갱신 후 진행한다.
