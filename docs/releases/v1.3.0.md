# v1.3.0 - 2026-05-26

DockMode의 대규모 기능 확장과 디자인 리뉴얼을 통합 반영한 정식 릴리즈 빌드입니다. 8종의 대기화면 시각 프리셋, 6종 테마, 로컬 갤러리 연동 슬라이드쇼, 조도 센서 기반 실시간 야간 모드 및 태블릿 5:5 대칭 분할 최적화 레이아웃이 적용되었습니다.

## 주요 변경 사항

### 1. 8종 시각 프리셋 & 6종 테마 도입
* **8종 대기화면 프리셋**: Minimal Clock, Warm Bedside, OLED Night Clock, Split Dashboard, Calendar Board, Battery Dock, Photo Frame 등 다양한 컨셉의 화면 구성 제공
* **6종 테마 프리셋**: Midnight Glass, Warm Bedside, OLED Pure Black, Aurora Gradient, Paper Calendar, Material You 테마를 통해 취향에 맞는 조명과 톤 실시간 전환 지원
* **저장 및 제스처**: 설정된 프리셋/테마는 DataStore를 통해 재시작 시 자동 복원되며, 대기 화면 내 좌우 스와이프 제스처로 빠른 프리셋 전환이 가능합니다.

### 2. 로컬 갤러리 슬라이드쇼 & 반응형 Empty UI
* **갤러리 연동**: 미디어 권한 획득 시 ContentResolver를 통해 로컬 사진을 비동기 조회하여 10초 주기로 교차 페이드(Crossfade) 회전하는 액자 슬라이드쇼 제공
* **반응형 Empty UI**: 하드코딩된 더미 문자열을 완전히 제거하고, 갤러리 권한 미획득 상태와 갤러리 내 이미지 부재 상황에 따라 아름다운 안내 가이드 다국어(ko/en) 렌더링 구축

### 3. 조도 센서 기반 자동 야간 모드
* **실시간 lux 감지**: `Sensor.TYPE_LIGHT` 하드웨어 센서를 Lifecycle-safe Flow로 감지
* **4단계 감도 설정**: 침실(5 lx), 어두움(10 lx), 은은함(20 lx), 실내(50 lx) 중 임계 감도를 설정할 수 있으며, 주변 조도가 이보다 어두워지면 OLED Pure Black 저휘도 야간 테마로 자동 매핑 전환되어 야간 눈부심을 완벽하게 차단합니다.

### 4. 태블릿 및 폴더블 최적화
* **웅장한 가로 분할**: 가로 폭 600dp 이상의 대화면 기기 진입 시 웅장하고 미려한 좌우 5:5(1f : 1f) 대칭 칼럼 레이아웃 튜닝 적용

### 5. 빌드 / CI / 의존성
* **의존성**: Coil Compose, Navigation Compose, Material Icons Extended 정식 추가
* **버전 정보**: `versionCode` 3 → 4, `versionName` "0.1.2" → "1.3.0"

## 검증
* **로컬 정적 분석**: `./gradlew ktlintCheck detekt testDebugUnitTest` 100% 통과 완료
* **로컬 빌드**: `./gradlew assembleDebug` 성공 (디버그 APK 산출물 생성 확인)
* **CI 검증**: 원격 GitHub Actions 빌드 성공 검증 예정
