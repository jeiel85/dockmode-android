# v0.1.1 - 2026-05-23

DockMode 첫 Play Store 출시용 signed 빌드입니다. 코드/디자인은 v0.1.0 기준에서 변경이 없으며, versionCode만 2로 올리고 Play App Signing용 업로드 키스토어로 서명한 AAB를 생성합니다.

## 변경 사항

- **Build**: `versionCode` 1 → 2, `versionName` 0.1.0 → 0.1.1
- **Build**: GitHub Actions Secrets로 등록된 업로드 키스토어(`dockmode-upload`)로 release AAB 자동 서명. v0.1.0의 unsigned AAB를 대체하여 Play Console 업로드 가능한 산출물 생성.

## 검증

- 로컬: `./gradlew ktlintCheck detekt assembleDebug bundleRelease` 모두 SUCCESSFUL
- CI: 태그 푸시 후 Android CI 결과 확인
- 산출물:
  - `dockmode-v0.1.1-debug.apk`
  - `dockmode-v0.1.1-release.aab` (signed)
  - `dockmode-v0.1.1-mapping.txt`

## Play Console 업로드

1. `dockmode-v0.1.1-release.aab`를 Play Console → 출시 → 테스트 → 내부 테스트 → 새 버전 만들기에 업로드
2. 출시 노트는 [play_store/release_notes/v0.1.1.txt](../../play_store/release_notes/v0.1.1.txt) 한국어/영어 블록을 복사
3. mapping.txt는 Play Console → ProGuard 매핑에 별도 업로드

## 알려진 제약

- v0.1.0 시점 한계가 그대로 적용됩니다 (정식 앱 아이콘은 `play_store/graphics/`로 보강, 본 빌드의 런처 아이콘은 같은 모티프의 어댑티브 아이콘).
- 라이트 모드 경로 검증, 장시간 번인 실측은 후속 작업.
