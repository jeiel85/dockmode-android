# v0.1.2 - 2026-05-23

설정 화면의 시계 스타일 선택 카드 미리보기를 정적 텍스트("12:00", "12:00:30", "12 / 일정")에서 실제 현재 시각 기반 동적 표시로 교체. 카드 안 미리보기가 매초 갱신되어 각 스타일이 실제로 어떻게 보이는지 더 정확하게 전달합니다.

## 변경 사항

- **UI**: `SettingsScreen` `ClockStyleSelectorSection`에서 `produceState`로 1초 주기 `nowMillis`를 받아 세 카드 미리보기를 동적 생성
  - 미니멀 카드: `HH:mm` (예: `14:32`)
  - 디지털 카드: `HH:mm:ss` (예: `14:32:45`)
  - 캘린더 중심 카드: `HH:mm · 일정` (locale별 텍스트)
- **String**: `settings_clock_style_calendar_preview_suffix` ko=`일정`, en=`Events` 추가
- **Build**: `versionCode` 2 → 3, `versionName` 0.1.1 → 0.1.2

## 검증

- 로컬: `./gradlew ktlintCheck detekt` 모두 SUCCESSFUL
- CI: 태그 푸시 후 Android CI 결과 확인 (signed AAB 자동 생성)
- 산출물: `dockmode-v0.1.2-debug.apk`, `dockmode-v0.1.2-release.aab` (signed), `dockmode-v0.1.2-mapping.txt`
